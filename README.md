# ZeroScript Studio — Android

Proyecto Android ZeroScript Studio, versión 1.5.5-mobile.

## Compilar el APK
1. Sube el archivo `ZeroScriptStudio-App-src.zip` a la raíz de este repositorio.
2. Abre la pestaña **Actions** y ejecuta **Build APK** (o espera a que se active con el push).
3. Cuando termine, abre la ejecución y descarga el artefacto **ZeroScriptStudio-apk**.
4. Dentro encontrarás `app-debug.apk`.

El workflow extrae el ZIP y compila con Java 17 y Gradle 8.9.
